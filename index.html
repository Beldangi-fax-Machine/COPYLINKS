Install Homebrew

Homebrew is the package manager for the Mac. Everything else here installs through it.

1 Open Terminal

Press ⌘ Space, type Terminal, press Return. A text window opens — that's where everything below goes.

2 Paste the install command

Copy this, paste it into Terminal, press Return, then follow the prompts. It will ask for your Mac password (typing stays invisible — that's normal).

$ /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

3 Add Homebrew to your PATH

On Apple Silicon, the installer prints two lines at the end to run. They look like this — paste them so the brew command is found in new terminals.

$ echo >> ~/.zprofile
$ echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
$ eval "$(/opt/homebrew/bin/brew shellenv)"

On an Intel Mac, Homebrew installs to /usr/local and the PATH step is handled automatically — you can skip step 3.

Install Git

Git tracks every change to your code so you can branch, undo, and collaborate without fear.

1 Install with Homebrew

$ brew install git

2 Tell Git who you are

Git stamps your name and email on every commit. Set them once, globally.

$ git config --global user.name "Your Name"
$ git config --global user.email "you@example.com"

macOS ships with an old Git from Apple. Installing through Homebrew gives you the current version and keeps it updated with brew upgrade.

Install tmux

tmux splits one terminal into many panes and windows — and keeps them running even if you close the terminal. It's how you'll run several Claudes at once.

1 Install with Homebrew

$ brew install tmux

2 Start your first session

This opens a tmux session named main. You'll see a green status bar appear at the bottom — that means you're inside tmux.

$ tmux new -s main

Install Claude Code

Claude Code is Anthropic's AI coding agent that lives in your terminal — it reads your project, edits files, runs commands, and handles Git for you.

Recommended — native installer (auto-updates)

1 Run the install script

No Node.js needed. This drops a self-contained binary in ~/.local/bin and keeps itself up to date in the background.

$ curl -fsSL https://claude.ai/install.sh | bash

2 Open a new terminal tab, then launch

A fresh tab picks up the updated PATH. Run claude inside any project folder — the first launch opens your browser to sign in.

$ claude

Alternative — through Homebrew

Prefer to keep everything under Homebrew? This works too. Note that the Homebrew build doesn't auto-update — run brew upgrade claude-code to update it.

$ brew install --cask claude-code

Claude Code needs an active Claude Pro, Max, Team, or Enterprise plan, or an Anthropic Console account with API credit. Installing is free; running it is not.

Verify everything installed

Each command should print a version number. If one says "command not found," open a brand-new terminal tab and try again.

$ git --version
$ tmux -V
$ claude --version

Have Claude check its own health

This diagnoses install, PATH, and auth issues and tells you exactly what to fix.

$ claude doctor

Git — essential commands & help

Git is typed, not chorded. These nine commands cover the everyday loop. When you're stuck, the help system is built in.

Your help key

git helpList the most common commands
git help <command>Open the full manual page, e.g. git help commit
git <command> -hQuick one-screen summary of a command's options

The everyday loop

git initStart tracking the current folder
git statusSee what's changed and what's staged
git add .Stage all your changes for the next commit
git commit -m "msg"Save a snapshot with a message
git log --onelineBrowse history, one line per commit
git switch -c nameCreate and move to a new branch
git pullPull down others' changes
git pushSend your commits to the remote

tmux — the prefix & help

Every tmux shortcut starts with the prefix: press Ctrl+b, release, then press the next key. So "Ctrl+b then c" means hold Ctrl+b, let go, tap c.

Your help key

Ctrl+b ?List every key binding (press q to exit the list)

Windows — like browser tabs

Ctrl+b cCreate a new window
Ctrl+b ,Rename the current window
Ctrl+b n / pNext / previous window
Ctrl+b 0…9Jump straight to window by number
Ctrl+b wPick a window from a visual list

Panes — split one window into many

Ctrl+b %Split left / right
Ctrl+b "Split top / bottom
Ctrl+b ←↑↓→Move focus between panes
Ctrl+b zZoom the current pane full-screen (again to undo)
Ctrl+b xClose the current pane

Sessions — leave & come back

Ctrl+b dDetach — work keeps running in the background
tmux lsList running sessions
tmux attach -t mainRe-attach to a session by name

The payoff: three Claudes in one tmux window

Run several Claude Code sessions at once — one per project, or several on the same repo working different tasks. Two ways: the hands-on path so you learn the keys, and a one-shot script once you're comfortable.

Path A — do it by hand (learn the keys)

1 Start a fresh session

$ tmux new -s claude

2 Split the window into three panes

Press the prefix then the split key. Do it twice to get three panes side by side.

Ctrl+b %Split into left + right
Ctrl+b %Split the focused pane again → three panes
Ctrl+b SpaceCycle layouts until they're evenly tiled

3 Launch Claude in each pane

Move between panes with Ctrl+b then an arrow key. In each one, go to a project and start Claude:

pane 1 ▸ cd ~/projects/app-one && claude
pane 2 ▸ cd ~/projects/app-two && claude
pane 3 ▸ cd ~/projects/app-three && claude

4 Step away without stopping them

Detach with Ctrl+b then d. All three Claudes keep running. Come back any time:

$ tmux attach -t claude

Prefer windows over panes? Use Ctrl+b c to make a new full-screen window for each Claude, then jump between them with Ctrl+b 0/1/2. Panes show all three at once; windows give each one room to breathe.

Path B — one command does all of it

Once you understand the pieces, this builds a tiled session with three panes, each already running Claude, and drops you straight into it. Edit the cd paths to your own projects.

$ tmux new-session -d -s claude -c ~/projects/app-one  'claude' \
    \; split-window -h -c ~/projects/app-two   'claude' \
    \; split-window -h -c ~/projects/app-three 'claude' \
    \; select-layout even-horizontal \
    \; attach

That's the whole workflow: Homebrew installs your tools, Git tracks your work, tmux holds the panes open, and three Claudes work in parallel. You're set up like a pro.
